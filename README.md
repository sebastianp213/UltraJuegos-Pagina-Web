
UltraJuegos es una página web de compra de videojuegos desarrollada con HTML y CSS.

El proyecto simula una tienda online gamer con distintas secciones, categorías y páginas individuales para cada juego.

---

## 🚀 Características

- Página principal con juegos destacados
- Sección de ofertas
- Juegos agregados recientemente
- Categorías separadas por género
- Página individual para cada juego
- Requisitos mínimos de los juegos
- Diseño oscuro estilo gamer
- Navegación entre páginas
- Uso de Flexbox y Box Model

---

## 🕹️ Categorías disponibles

- Acción
- Carreras
- Terror
- RPG
